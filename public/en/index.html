Agentic AI Korea

A community in Korea that learns open source for AI agents together, in Korean, and contributes to the projects.
Building on projects hosted by the Agentic AI Foundation (AAIF), we cover topics from agent runtimes to inference infrastructure.

10 projects hosted by the Agentic AI Foundation (AAIF)

The Agentic AI Foundation is a neutral, open foundation under the Linux Foundation that hosts open protocols and open source projects for agentic AI.
It launched in December 2025 and hosts 10 projects as of November 2026.

ProjectDescription
MCP (Model Context Protocol)A protocol for connecting LLM applications to external data sources and tools
gooseAn open source, extensible AI agent that works with any LLM
AGENTS.mdA simple, open format for guiding coding agents
agentgatewaySecure, scalable connections between AI agents, models, tools, and APIs
A2A (Agent2Agent)An open protocol for AI agents to communicate, collaborate, and exchange information and tasks across platforms and frameworks
Agent RouterAn open source AI gateway built on Envoy that connects applications to models and MCP tools
Agent SkillsAn open format for reusable agent expertise
Open ResponsesA shared LLM API format for agents across providers
OpenEnvOpen environments for training AI agents
OpenSandboxA general purpose sandbox platform for AI applications

MCPA practice materials

MCPA (Model Context Protocol Associate) is the first certification from the Agentic AI Foundation. AAIF ambassador Hoon Jo compiled these practice materials as a personal project.

  • 8 mock exams, 480 questions in total (English questions with Korean translations and explanations)
  • A cheat sheet of terms in the MCP 2026-07-28 specification (Korean and English)
  • An exam overview with the weight of each domain (Korean)
  • A summary of changes in the 2026-07-28 specification (Korean)
See all materials (github.com/sysnet4admin/lf-certifications)

These are practice materials, not real exam questions, and they are not official Linux Foundation or AAIF materials.
