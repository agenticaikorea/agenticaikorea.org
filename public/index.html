에이전틱 AI 재단(AAIF)의 프로젝트 10개

에이전틱 AI 재단은 리눅스 재단 산하에서 AI 에이전트를 위한 오픈소스 프로토콜과 프로젝트를 중립적으로 운영합니다.
2025년 12월에 출범했고 2026년 11월 기준 10개 프로젝트를 호스팅하고 있습니다.

프로젝트설명
MCP (Model Context Protocol)LLM 애플리케이션을 외부 데이터와 도구에 연결하는 프로토콜
goose어떤 LLM과도 동작하고 기능을 확장할 수 있는 오픈소스 AI 에이전트
AGENTS.md코딩 에이전트에게 프로젝트 작업 방법을 알려 주는 간단한 오픈 포맷
agentgatewayAI 에이전트, 모델, 도구 그리고 API 사이의 연결을 안전하게 처리하는 게이트웨이
A2A (Agent2Agent)AI 에이전트끼리 통신하고 협업하도록 하는 오픈 프로토콜
Agent Router애플리케이션을 모델과 MCP 도구에 연결하는 Envoy 기반 오픈소스 AI 게이트웨이
Agent Skills에이전트가 재사용할 수 있는 전문 지식(스킬)을 담는 오픈 포맷
Open Responses모델 제공자가 달라도 같은 방식으로 호출할 수 있는 에이전트용 LLM API 포맷
OpenEnvAI 에이전트를 학습시키는 오픈소스 환경
OpenSandboxAI 애플리케이션을 위한 범용 샌드박스 플랫폼

앞으로 추가할 내용

사이트는 첫 화면만 먼저 만들었고 아래 내용은 행사를 이어 가면서 하나씩 올리겠습니다.

  • 행사 후기행사가 끝날 때마다 날짜, 참가자 수, 발표 자료 그리고 사진을 한 페이지에 기록하겠습니다.
  • 처음 참여하시는 분들을 위한 안내행사에 참여하는 방법과 AAIF 프로젝트에 처음 기여하는 방법을 설명할 예정입니다.

MCPA 준비 자료

MCPA(Model Context Protocol Associate)는 에이전틱 AI 재단의 첫 자격증입니다. 이 자격증을 준비하는 분들을 위해 AAIF 앰버서더 조훈이 개인적으로 정리한 연습용 자료입니다.

  • 모의고사 8세트, 총 480문항 (영어 문제에 한국어 번역과 해설)
  • MCP 2026-07-28 스펙 용어 치트시트 (한국어, 영어)
  • 시험 개요와 도메인별 비중 정리
  • 2026-07-28 스펙 변경점 정리
자료 전체 보기 (github.com/sysnet4admin/lf-certifications)

이 자료는 실제 시험 문항이 아니고 리눅스 재단과 AAIF의 공식 자료도 아닙니다.
